# Driving Simulator 3243

Браузерний навчальний прототип для ознайомлення з керуванням автомобілем та схемами маршрутів, наданими користувачем.

## Запуск і публікація
Проєкт є статичним сайтом: `index.html`, `styles.css`, `src/main.js` і папка `assets/routes`. Його можна опублікувати на GitHub Pages або Render Static Site без серверної частини. Для Render: Build Command залишити порожньою, Publish Directory — `.`.

## Поточний прототип
- Canvas-перспектива дороги, прості будівлі та зелені зони.
- Десять схем маршрутів, завантажуваних із `assets/routes`.
- Перемикання навчального та екзаменаційного режимів.
- Інтерфейс для МКПП/АКПП та двох ракурсів.
- Покажчики повороту, світло та навчальні пояснення ситуацій.
- Клавіатура WASD/стрілки, Q/E — поворотники, L — світло, C — камера.

## Межі достовірності
Це демонстраційна модель, а не точна 3D-реконструкція Броварів. Схеми маршрутів включені як довідкові зображення, але поки не перетворені на геоприв'язані дорожні траєкторії. Симуляція не моделює офіційний іспит ТСЦ МВС, юридично значущі штрафні бали, реалістичний трафік чи точну фізику автомобіля.

## План наступних етапів
1. Прив'язати кожну маршрутну схему до координат та перевірити її на актуальній карті.
2. Зробити повноцінну 3D-сцену з геометрією дороги й перехресть.
3. Додати правила пріоритету, дорожні знаки, світлофори, пішоходів та автомобілі трафіку.
4. Реалізувати перевірювану фізику МКПП/АКПП, зчеплення, гальм та керма.
5. Побудувати журнал помилок і систему оцінювання на основі підтверджених офіційних критеріїв.
6. Підключити український голосовий супровід та звіт про тренування.

Навчальна допоміжна система. Не замінює уроки з інструктором і не є офіційним продуктом ТСЦ МВС.
